### **ICSI-409-CYK-Algorithm**


### **What is this?**
This program is a CYK algorithm to determine whether a given string is in a CFG or CNF. The CYK algorithm works by using a dynamic programming approach, filling in a matrix to determine if each substring of the input string can be generated by programming the CFG. 

### **What does it do?**
This CYK program will be able to read context-free grammar from a file and generate the corresponding parse table for a given input string. 

### **How to run the program:**

**Download and Extract**

Download the ZIP file and extract it to a folder.

**Set Up Input File**

Ensure input.txt is in the src folder.

**Compile and Run**

Open a terminal, navigate to the src folder, and run:

javac CYK.java
java CYK

**View Results**

The output will display the parsed grammar, DP table, and whether the input string is accepted. It will produce the table output. Be sure to NOT use any non-terminals longer than length 1 such as 'Za' or 'R1'
